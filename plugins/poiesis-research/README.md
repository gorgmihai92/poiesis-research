# poiesis-research

Research you can check: the literature on a topic, the evidence behind a claim, and EU and Romanian grants. The
`research` skill picks a playbook (literature, evidence, funding); the agents `paper-scout`, `evidence-scout` and
`funding-scout` run one part each, in parallel.

The plugin of [Poiesis Research](https://github.com/gorgmihai92/poiesis-research), one of the four products in the
Poiesis Toolkit: Research collects, Insight connects, Frontier explores, Design creates ([Poiesis
Insight](https://github.com/gorgmihai92/poiesis-insight), [Poiesis
Frontier](https://github.com/gorgmihai92/poiesis-frontier), [Poiesis
Design](https://github.com/gorgmihai92/poiesis-design)).

```
/plugin marketplace add gorgmihai92/poiesis-research
/plugin install poiesis-research@poiesis-research
```

Full guide: https://github.com/gorgmihai92/poiesis-research#readme
